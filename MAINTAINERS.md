# Maintainers

Maintainers steward the `evidence.v1` specification and this reference implementation:
they review and merge changes ([`CONTRIBUTING.md`](CONTRIBUTING.md)), follow the
change process in [`GOVERNANCE.md`](GOVERNANCE.md), and handle security and conduct
reports ([`SECURITY.md`](SECURITY.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)).

|---|---|
| mlgorithm | [@mlgorithm](https://github.com/mlgorithm) |

Security issues: use GitHub private vulnerability reporting (see `SECURITY.md`) — please
do not open a public issue.
